# Button Atlas

採用された38種類のボタンを比較・評価する、依存ライブラリーのないHTML/CSS/JavaScriptギャラリーです。`index.html`を直接開くか、次のローカルサーバーで閲覧できます。

```sh
python3 -m http.server 8000
```

`/workspace/uilib/verdicts.tsv`のADOPTを採用し、`candidates.md`のfill / shape / contentと表現定義を保持しています。n03はe01の写真背景オプション、n13はn12の横長FABオプションとして注記。n01は2/3採用、ほかは3者採用です。各カードの日本語の一行メモは議論理由の要約です。原文と投票内容は`data/variants.json`に保存しています。

- 塗り・かたち・コンテンツで絞り込み、リセットで全件表示。
- プレビューは実際の`button`。共通ラベルは`Get started`で、アイコンやドット文字は独自SVGです。アイコンのみのボタンにも同じアクセシブル名を設定。
- セグメントは開始・選択確定・追加の三つの操作、スプリットは実行＋メニュー。通常・ホバー・押下・フォーカス・無効の行は`inert`かつ読み上げ対象外です。
- OK / NG / 保留と理由をlocalStorageの既存キー`button-atlas-reviews-v1`に保存。JSON書き出し・読み込みは既存schemaVersion 1と互換性があります。読み込みは一致するIDの評価をマージし、形式・サイズを検証します。
- 処理中デモと危険な操作の切り替えを維持。通常のプレビューはダイアログを開きます。
- 390pxで1列、画面幅に応じて2〜4列。キーボードフォーカス、ダークモード、動きを減らす設定に対応。

`tokens.css`はプリミティブ→意味→コンポーネントの3層。素材や各案の調整はコンポーネントトークンと`style.css`のID別ルールで定義しています。外部フォント・画像・CDNへの依存はありません。ガラス背景・金属・粒子もローカルCSS/SVGで描画します。

`data/sources.json`は既存調査の参照アーカイブです。存在する参照だけをカードで表示し、採用条件や頻度として扱いません。新しい案に参照を推測して追加していません。過去の調査メタデータはアーカイブ内に保持しています。

編集後は次を実行してください。ビルドはネットワーク不要で、`sources.json`を変更しません。

```sh
python3 scripts/build-data.py
python3 scripts/check-data.py
node --check app.js
# ローカルサーバーを起動した状態で（PlaywrightとChromeが必要）
node scripts/check-ui.cjs
```

`check-data.py`は38件のID、採用メモ、統合注記、元の参照の保持、ブラウザー用データとの一致、基本的な画面契約を確認します。隣の`uilib/verdicts.tsv`が存在する場合は採用リスト・投票・理由原文との一致も検証します。ブラウザーでは390pxとデスクトップ、絞り込み、評価の再読み込み、JSON往復、キーボード操作を確認してください。localStorageが利用できない環境では通知が表示され、JSONで保存できます。

Opus再レビュー対応: 38案を保持し、近似案は色・素材・ステージで差別化。非CTAの6案には用途タグを表示します。状態見本は2列・60%サイズで表示し、素材を保つオーバーレイでホバーと押下を区別します。
